❖架构与工作链路Architecture

链路分工一句话：GPT6-ASTRA 通过代码硬编码决定「长什么样、怎么动」，PhysX-Omni / 多模态模型（也可以是 GPT6-ASTRA）判断「多重量级、这看起来像什么材质」，规范给定「摩擦与恢复是多少」。

工作链路：每一环的产物即下一环的输入

  1. 视频解析

    抽帧 + 元数据，形成只读证据集

    外观轨 + 交互轨（1080p）→参考帧集

  2. 物性推理

    Omni VLM + Agent 多模态

    参考帧→逐部件材质 / 密度 / 模量 + 尺寸锚

  3. 外观建模

    编码代理写程序化脚本（共用几何库 + 专属脚本）

    参考帧→几何 / 材质 / UV / 贴图（blend · visual.usdc）

  4. 物理装配

    刚体四件套 + 关节（类型 / 轴 / 限位 / 驱动）

    建模脚本→physics.usda

  5. 属性补全（融合层）

    类别证据链 + 密度钳制；只增不改

    资产 + 推理 + 完整物理规范→physics:* / 物理材质绑定

  6. 标准收口

    三格式导出 + 五项结构要求

    补全后资产→USD / MJCF / URDF / blend

  7. 验证

    Newton + MuJoCo 逐项断言；三路渲染互校

    交付资产 + 参考帧→断言记录 / 对照图 / 录像

  8. 复审与打包

    逐项复审，批次快照可回滚

    验证证据→交付包 + manifest

十二个维度：每一项内容如何产生

外观建模不是「生成后处理」，而是把视频里的结构关系翻译成代码。以一件无线鼠标为例，其专属脚本可直接读到：

base = group('MouseBody', (0, 0, .002), .080, iner=[.00008, .00008, .000025])   # 质量与惯量显式给出
def width(y):                                                                  # 侧壁轮廓：解析函数
    if y < -.027:  return .002 + math.sqrt(max(0, .028**2 - (y + .027)**2))
    if y >  .045:  return .020 + math.sqrt(max(0, .010**2 - (y - .045)**2))
    return .030
joint('WheelPress', base, wc, [0, 0, -1], [0, .0006], stiff=950, damp=.6)       # 类型 / 轴 / 行程 / 刚度 / 阻尼

在这里，「怎么动」与「长什么样」由同一份代码、同一次判断给出——这正是生成式路线必须拆成两次估计、且拆开后无人能逐项核对的部分。

可仿真资产的十二个维度按来源分两类——7 项由代码直接写出，5 项由测量与确定性计算补全，没有一项数值取自生成模型。 对任何一件可动物品，每个维度的内容都按固定的方式产生：

代码直接写出 · 7 项 测量与确定性计算补全 · 5 项
外观层

几何——编码代理对照参考帧逐件手写程序化建模：轮廓为解析函数，结构靠布尔与放样，不用生成式网格； UV——smart_project 展开 + 代码显式指定； 贴图——印刷与纹理从参考帧透视校正后采样，不绘制、不生成； 材质——视觉面由代码节点定义，物理面（摩擦 / 恢复）按类别取自完整物理规范。

结构层

部件——建模时随结构与配合关系一次划定，无需事后分割； 语义——代码即语义，物性类别走四级证据链（多模态推理 → USD 材质名 → 组名 → 人工定类）； 尺度——参考帧比例推定 + 尺寸锚先验，标注 dimensionsMeasured = false。

物理层

关节——类型（转动 / 滑动）与配合在代码中直接写出； 轴向——四元数显式定轴； 限位——上下限与行程直接写出； 质量——作者原值优先，缺失时以「实测质量 ÷ 体积」在先验区间内钳制补写； 碰撞——解析基元为主、convex_hull 辅助。

三条纪律：① 没有视频依据的东西不加——与生成模型「补全、美化」的默认倾向相反，某鼠标重建时移除了无依据的品牌标识与多余按键； ② 隐含量显式化——质量、惯量、关节参数都写在代码里，不留待下游推导；③ 不确定的标为近似，列入「不声称」清单（尺寸为比例推定，材质与刚度为近似）。

融合层由 Agent AI（多模态）参与审计与匹配融合——物性先验按语义部件挂接到物理刚体，属性只增不改； 验收以 USD / MJCF / blend 三格式收口，物理侧 Newton 与 MuJoCo 交叉断言、渲染侧三路互校，复审不通过则回流主链。
